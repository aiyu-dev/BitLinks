# BitLinks - Smart & Reliable URL Shortener 🔗🚀

BitLinks is a full-stack web application designed to simplify link management. It allows users to transform long, complex URLs into clean, shareable short links. Built with a modern tech stack, the app ensures data persistence and a seamless user experience across all devices.

## 🌟 Key Features
- **⚡ Custom Short Links:** Generate personalized short URLs for your favorite sites.
- **📁 Persistent Storage:** Integrated with MongoDB to store and manage redirected links securely.
- **📱 Fully Responsive:** Optimized for mobile, tablet, and desktop.
- **📄 Multi-Page UI:** Includes professional 'About', 'Contact', and 'Shorten' sections.
- **🚀 Fast Redirection:** High-performance routing using Next.js Server Side logic.

## 🛠️ Tech Stack
- **Framework:** Next.js (React) ⚛️
- **Database:** MongoDB (via Mongoose) 🍃
- **Styling:** Tailwind CSS 🎨
- **Icons/Assets:** Custom SVGs and professional typography.

## 📖 Installation & Setup
1. Clone the repo: `git clone https://github.com/astoriaking15/BitLinks.git`
2. Install dependencies: `npm install`
3. Create a `.env` file and add your `MONGODB_URI`.
4. Start the dev server: `npm run dev`
